## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please **do not** report it in a public issue, discussion, or pull request.

### How to Submit a Report
* **Private Disclosure:** Send an email to `team@lmdpro.app` *(replace with your team's security email address)* or use GitHub's [Private Vulnerability Reporting](https://docs.github.com/en/code-security/repository-security-advisories/configuring-private-vulnerability-reporting-for-a-repository) feature if enabled for this repository.
* **Information Needed:**
  * A clear description of the vulnerability and its potential impact.
  * Detailed steps to reproduce the issue (including proof-of-concept scripts or payload examples, if applicable).
  * The exact environment details and software versions affected.

### What to Expect
* **Initial Response:** We will acknowledge receipt of your vulnerability report within **48 hours**.
* **Progress Updates:** We will notify you of our findings and planned remediation steps within **5 business days**.
* **Fix & Public Advisory:** Once a patch is confirmed and deployed for all supported versions, a public security advisory will be published crediting your report (unless you prefer to remain anonymous).

### Responsible Disclosure Guidelines
We ask that you give us a reasonable timeframe to resolve the issue before publishing details to the public. We appreciate your assistance in keeping our users safe!
