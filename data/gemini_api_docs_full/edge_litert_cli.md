The LiteRT Command Line Interface (CLI) is a convenient toolkit to streamline
[LiteRT](/edge/litert) development workflows. It supports converting,
quantizing, compiling, running, benchmarking, and visualizing LiteRT
(`.tflite`) models on various hardware (CPU, GPU, NPU) across platforms
(desktop, mobile, or cloud).

See [LiteRT CLI GitHub](https://github.com/google-ai-edge/LiteRT-CLI) for more details.

**Note:** The LiteRT CLI is an early preview under active development. It has
limited platform and feature support.

## Key Capabilities

* **[Installation](https://developers.google.com/edge/litert/cli/installation)**: Quick setup using `uv` or `pip`.
* **[Common Commands](https://developers.google.com/edge/litert/cli/commands)**: Streamlined workflows for
  downloading, converting (`PyTorch` / `Hugging Face`), quantizing, AOT
  compiling, running, benchmarking, and visualizing models.
* **[Troubleshooting & Resources](https://developers.google.com/edge/litert/cli/troubleshooting)**: Verified
  platforms, Colab notebooks, quick start demos, and common fixes.

To get started, proceed to the [Installation](https://developers.google.com/edge/litert/cli/installation) guide.
