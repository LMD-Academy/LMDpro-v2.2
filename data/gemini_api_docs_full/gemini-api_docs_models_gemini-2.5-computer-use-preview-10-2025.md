# Gemini 2.5 Computer Use model

[//]: # (source: [ai.google.dev](https://ai.google.dev/gemini-api/docs/models/gemini-2.5-computer-use-preview-10-2025))

The [Interactions API](/gemini-api/docs/interactions-overview) is now generally available. We recommend using this API for access to all the latest features and models.

**Note:** The [Gemini 3](/gemini-api/docs/models#gemini-3) Pro and Flash models support built-in computer use, without the need for a separate model.

An agentic capability model designed for direct interface interaction, allowing
Gemini to perceive and navigate digital environments. Gemini 2.5 Computer Use is
best for browser automation, multi-step software tasks, and UI testing that
requires visual reasoning and precise cursor control.

## Documentation

of features and capabilities.
