# Gemini Omni Flash

[//]: # (source: [ai.google.dev](https://ai.google.dev/gemini-api/docs/models/gemini-omni-flash))

The [Interactions API](/gemini-api/docs/interactions-overview) is now generally available. We recommend using this API for access to all the latest features and models.

**Note:** Gemini Omni Flash is in **preview**.

Gemini Omni Flash is a preview model designed for fast, conversational video
generation and editing. It excels at turning text and images into video,
lets you refine and edit generated videos through natural language
conversations using the Interactions API.

[Try in Google AI Studio](https://aistudio.google.com?model=gemini-omni-flash-preview)

## Documentation

Visit the [Gemini Omni Flash](/gemini-api/docs/omni)
page for full coverage of features and capabilities.
