AMP is a research agent that uses the skills CLI to load procedural knowledge for engineering, design, and operational tasks.

## Install skills on AMP

The skills CLI installs SKILL.md files into your repository so AMP can reference them across sessions. Run the command below from your project root, then start a new AMP session.

`$ npx skills add <owner>/<repo>`

New to skills? Start with the [documentation](/docs) or browse the [full directory](/).
