Google's developer agent platform. Skills installed via the skills CLI extend Antigravity sessions with reusable, project-scoped guidance.

## Install skills on Antigravity

The skills CLI installs SKILL.md files into your repository so Antigravity can reference them across sessions. Run the command below from your project root, then start a new Antigravity session.

`$ npx skills add <owner>/<repo>`

New to skills? Start with the [documentation](/docs) or browse the [full directory](/).
