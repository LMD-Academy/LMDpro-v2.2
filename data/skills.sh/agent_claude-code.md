## Install skills on Claude Code

The skills CLI installs SKILL.md files into your repository so Claude Code can reference them across sessions. Run the command below from your project root, then start a new Claude Code session.

`$ npx skills add <owner>/<repo>`

Run `npx skills add <repo>` from your project root. Claude Code picks up SKILL.md files automatically the next time you start a session.

New to skills? Start with the [documentation](/docs) or browse the [full directory](/).
