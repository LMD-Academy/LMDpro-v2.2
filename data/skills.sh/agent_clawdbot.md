ClawdBot supports the skills CLI for installing reusable procedural knowledge across agent sessions.

## Install skills on ClawdBot

The skills CLI installs SKILL.md files into your repository so ClawdBot can reference them across sessions. Run the command below from your project root, then start a new ClawdBot session.

`$ npx skills add <owner>/<repo>`

New to skills? Start with the [documentation](/docs) or browse the [full directory](/).
