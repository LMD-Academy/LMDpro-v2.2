Factory's autonomous engineering agent. Compatible with the skills CLI for installing skills that Droid loads into its project context.

## Install skills on Droid

The skills CLI installs SKILL.md files into your repository so Droid can reference them across sessions. Run the command below from your project root, then start a new Droid session.

`$ npx skills add <owner>/<repo>`

New to skills? Start with the [documentation](/docs) or browse the [full directory](/).
