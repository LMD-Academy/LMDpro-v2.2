# Contact

[//]: # (source: [skills.sh](https://skills.sh/contact))

How to reach the skills.sh team.

## Security

To report a security issue with a skill or with this site, please use Vercel's coordinated disclosure process at [security.vercel.com](https://security.vercel.com/). If you believe a skill listed in the directory is malicious, please include the skill URL in your report.

## Bugs and feature requests

File an issue on the public repository at [github.com/vercel-labs/skills](https://github.com/vercel-labs/skills/issues). That includes both the CLI and this directory.

## Partnerships and press

For partnership inquiries (security audit providers, agent integrations, partner directories) or media requests, reach out via the partner form on [vercel.com/contact](https://vercel.com/contact). Mention skills.sh in your message.

## Skill author requests

If you publish skills and want a listing corrected, hidden, or redirected (deprecated, renamed, moved), open a pull request against [vercel-labs/skills](https://github.com/vercel-labs/skills) with the change. The repository README documents the manifest format used to manage hidden and redirected skills.
