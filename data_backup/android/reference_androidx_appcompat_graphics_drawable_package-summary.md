## Classes

|  |  |
| --- | --- |
| `AnimatedStateListDrawableCompat` | A `Drawable` providing animated transitions between states. |
| `DrawableContainerCompat` | A helper class that contains several `Drawable`s and selects which one to use. |
| `DrawableWrapperCompat` | Drawable which delegates all calls to its wrapped `Drawable`. |
| `DrawerArrowDrawable` | A drawable that can draw a "Drawer hamburger" menu or an arrow and animate between them. |
| `StateListDrawableCompat` | Lets you assign a number of graphic images to a single Drawable and swap out the visible item by a string ID value. |
