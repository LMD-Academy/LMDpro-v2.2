## Why LiteRT-LM?

![](https://developers.google.com/static/edge/litert/images/landing/crossplatform.png)

### Cross-platform

Deploy LLMs across Android, iOS, Web, and Desktop.

![](https://developers.google.com/static/edge/litert/images/landing/hardware.png)

### Hardware accelerated

Maximize performance with GPU and NPU acceleration.

![](https://developers.google.com/static/edge/litert-lm/images/genAI.jpg)

### Broad GenAI Capabilities

Support for popular LLMs as well as multi-modality (Vision, Audio) and Tool Use.

### [Python](https://developers.google.com/edge/litert-lm/python)

Python APIs with hardware acceleration on Linux, MacOS, Windows, Android, and Raspberry Pi.

### [Android](https://developers.google.com/edge/litert-lm/android)

Native Android apps and JVM-based desktop tools.

[Android Guide](https://developers.google.com/edge/litert-lm/android)

### [iOS](https://developers.google.com/edge/litert-lm/swift)

Native iOS (macOS coming soon) Swift APIs.

[Swift Guide](https://developers.google.com/edge/litert-lm/swift)

### [Web](https://developers.google.com/edge/litert-lm/js)

JavaScript and TypeScript APIs for browser-based web apps with WebGPU acceleration.

[Web Guide](https://developers.google.com/edge/litert-lm/js)

### [Flutter](https://developers.google.com/edge/litert-lm/flutter)

Build cross-platform Flutter apps using the community-maintained flutter\_gemma package.
