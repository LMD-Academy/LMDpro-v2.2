# Model Conversion Stay organized with collections Save and categorize content based on your preferences.



LiteRT requires models to be in a specialized format for on-device execution.
This step is commonly referred to as "conversion" and uses LiteRT conversion
components to convert from one model format to LiteRT's representation.

## Multi-Framework Conversion Support

LiteRT supports converting models from PyTorch and TensorFlow.

See the following pages for more details:

* [Converting from PyTorch](https://developers.google.com/edge/litert/conversion/pytorch/overview.md)
* [Converting from TensorFlow](https://developers.google.com/edge/litert/conversion/tensorflow/overview.md)
* [Converting from JAX](https://developers.google.com/edge/litert/conversion/jax/overview.md)
