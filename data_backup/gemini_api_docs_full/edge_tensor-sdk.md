### Custom-designed SOCs developed by Google.

Unlock peak performance with Google Tensor that powers Google's Pixel devices.

The Google Tensor SDK is a specialized software toolkit that allows developers to optimize and run machine learning models directly on the Tensor Processing Unit (TPU) found in Pixel devices.
