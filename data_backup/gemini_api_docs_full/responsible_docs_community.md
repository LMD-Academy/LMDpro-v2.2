# Join the Google Developer Community



Are you interested in chatting with Googlers and other developers about
responsible AI Practices?

Join the [Google Developer Community](https://discord.gg/google-dev-community) Discord server!
This is a great place to interact with developers, and to learn, share, and
support each other. You can find us in the `#gemma`, `#research`, and
`#ai-general` channels. See you there!

**Tip:** If you're new to Discord, check out this
[beginner guide](https://support.discord.com/hc/en-us/articles/360045138571-Beginner-s-Guide-to-Discord) to familiarize yourself with the platform.

For more local connections, you can join a
[Google Developer Group](https://developers.google.com/community/gdg) (GDG) in your area. There are over
1000 GDGs across 140 countries that offer the chance to connect with others near
you on a range of topics, including GenAI, responsibility, and more general
developer topics.
