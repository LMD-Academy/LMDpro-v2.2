# Skills for Cline

Open-source autonomous coding agent for VS Code. Reads SKILL.md files installed via the skills CLI to apply project-specific patterns automatically.

## Install skills on Cline

The skills CLI installs SKILL.md files into your repository so Cline can reference them across sessions. Run the command below from your project root, then start a new Cline session.

`$ npx skills add <owner>/<repo>`

New to skills? Start with the [documentation](/docs) or browse the [full directory](/).
