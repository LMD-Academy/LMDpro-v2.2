# Skills for Codex

OpenAI's coding agent. Compatible with the skills CLI for installing reusable procedural knowledge — performance rules, design systems, and workflow patterns.

## Install skills on Codex

The skills CLI installs SKILL.md files into your repository so Codex can reference them across sessions. Run the command below from your project root, then start a new Codex session.

`$ npx skills add <owner>/<repo>`

New to skills? Start with the [documentation](/docs) or browse the [full directory](/).
