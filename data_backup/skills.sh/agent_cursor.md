# Skills for Cursor

AI-first code editor with deep agent integration. The skills CLI installs SKILL.md files that Cursor agents reference automatically when working on the repo.

## Install skills on Cursor

The skills CLI installs SKILL.md files into your repository so Cursor can reference them across sessions. Run the command below from your project root, then start a new Cursor session.

`$ npx skills add <owner>/<repo>`

New to skills? Start with the [documentation](/docs) or browse the [full directory](/).
