# Skills for Gemini

Google's Gemini family of agents. Compatible with the skills CLI for repo-scoped skill installation — including the Gemini CLI for terminal workflows.

## Install skills on Gemini

The skills CLI installs SKILL.md files into your repository so Gemini can reference them across sessions. Run the command below from your project root, then start a new Gemini session.

`$ npx skills add <owner>/<repo>`

New to skills? Start with the [documentation](/docs) or browse the [full directory](/).
