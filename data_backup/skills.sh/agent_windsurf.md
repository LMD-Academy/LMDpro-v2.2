# Skills for Windsurf

Codeium's agentic IDE. Skills give Windsurf project-specific procedural knowledge that persists across sessions without manual re-prompting.

## Install skills on Windsurf

The skills CLI installs SKILL.md files into your repository so Windsurf can reference them across sessions. Run the command below from your project root, then start a new Windsurf session.

`$ npx skills add <owner>/<repo>`

New to skills? Start with the [documentation](/docs) or browse the [full directory](/).
