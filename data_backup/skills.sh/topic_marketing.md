# Marketing skills

Marketing skills give your agent domain expertise for SEO, copywriting, CRO, and growth work. Install once and your agent carries that knowledge into every session in the project without you re-explaining the context.

## What your agent can do with marketing skills installed

* Audit a landing page for SEO issues and return a prioritized action plan — not a generic checklist
* Write copy that applies behavioral psychology frameworks (Fogg model, social proof, loss aversion) rather than relying on style intuition alone
* Build a content brief from SERP analysis and keyword intent, mapped to what actually ranks for that query
* Design and write A/B test variants for landing pages, paywalls, and popups with testable hypotheses
* Draft cold email sequences with a coherent narrative arc across all touches
* Create a go-to-market plan with sequenced channels, messaging, and timing

## Frequently asked questions

How is this different from just prompting an agent with marketing context each session?+

Skills load persistent, structured domain knowledge. Without a skill, you re-explain your context every session. With one installed, your agent applies the same marketing frameworks automatically across every conversation in that project, including SEO priority ordering, CRO principles, and behavioral frameworks it would otherwise need you to specify.

Can I install individual skills instead of the full pack?+

Yes. npx skills add https://github.com/coreyhaines31/marketingskills --skill seo-audit installs only that skill. The full pack is more practical if you work across multiple marketing disciplines in the same project.

What is ai-seo and how does it differ from seo-audit?+

seo-audit covers traditional search: Google, technical SEO, on-page optimization, and crawlability. ai-seo covers AI search surfaces specifically, including how to structure content to appear in AI Overviews, Perplexity answers, and similar answer engines. The audiences are distinct and increasingly both matter for content-driven products.

Do I need to be a developer to use marketing skills?+

You need an agent that supports the skills CLI. If you're already using Claude Code, Cursor, or another coding agent, installation is a single command.
